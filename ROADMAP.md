# EduSaarthi AI — Future Scalability Roadmap

1. **Database Migration**: SQLite → PostgreSQL on AWS RDS or GCP Cloud SQL.
2. **Distributed Caching**: In-memory rate limiter → Redis cluster.
3. **Vector Database**: Local vector search → ChromaDB cloud or Pinecone vector database.
4. **Multilingual Support**: Support for regional Indian languages (Hindi, Tamil, Telugu, Kannada) for rural education impact.
5. **LMS Integrations**: LTI 1.3 standards integration for Canvas, Moodle, and Google Classroom.
